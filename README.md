# Eyal Yehudai – Personal Site

Personal site of Eyal Yehudai, built in the Frontend Development course at Ruppin Academic Center.
`index.html` is the home page: about, learning table, reading notes and a contact form.
`about.html` is the extended background and core competencies.
`notes.html` is my in-house camouflage armory project from my military service.
All three pages share one `styles.css`. Open with Live Server and validate with `npx html-validate@9 index.html about.html notes.html`.
